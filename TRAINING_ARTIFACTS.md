# Training Artifacts

Training is **optional reproduction**. The four checked-in `models/B_cross_script/fold*.ubj` files are the submission models. Do not retrain to replace them.

## Scripts in Git

| Script | Role |
|--------|------|
| `indexing/build_target_index.py` | Build source-ordered target sqlite + numeric-address postings |
| `indexing/build_address_index.py` | Build rare-address token postings and frequencies |
| `training/prepare_training.py` | External-memory feature shards / matrices |
| `training/train.py` | XGBoost fit (39 float32 features, ICU transliteration, frozen policy) |
| `training/audit.py` | Feature / retrieval parity against accuracy freeze |
| `training/ensemble_sanity.py` | Averaged four-fold score checks |
| `training/freeze.py` | Accuracy-freeze helpers |
| `training/validate_outputs.py` | TSV contract: order, subset, `max_matches=11` |
| `training/validate_extmem.py` | External-memory training checks |
| `training/verify_package.py` | Training package verification |
| `training/profile.py` | Optimized vs baseline feature parity/profile |
| `training/profile_extmem_scale.py` | External-memory scale profile |

These scripts expect historical local data originally under `v6_macro_f05/production_run_v2/` (eligible training sqlite, freeze checksums, shards). That tree is **not** in Git.

## Large artifacts NOT in Git

| Artifact | Purpose | Expected local path | Generated by |
|---|---|---|---|
| `v2_train_index.sqlite3` | Core SQLite index for candidate retrieval | `local_artifacts/v2_train_index.sqlite3` | `indexing/build_target_index.py` |
| `phase2_train_numeric_address.sqlite3` | Numeric address retrieval (`AN\|` keys) | `local_artifacts/phase2_train_numeric_address.sqlite3` | `indexing/build_target_index.py` (`--numeric-index`) |
| `train_address_index.sqlite3` | Rare-address overlap postings | `local_artifacts/train_address_index.sqlite3` | `indexing/build_address_index.py` |
| `train_target_store/` | Memory-mapped training targets | `local_artifacts/train_target_store/` | `training/prepare_training.py` |
| Feature shards / labels | Out-of-core XGBoost inputs | `local_artifacts/` or historical `v6_macro_f05/production_run_v2/training_shards/` | `training/train.py` / `prepare_training.py` |

Competition TSVs (`SOURCE2`/`SOURCE3`/`train` labels) stay in `dataset/` or `local_data/` and must not be committed.
